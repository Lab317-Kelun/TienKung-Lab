## 二、静摩擦 Fs 辨识（0xA1 力矩模式）

数据源：`motor_data_20260704_153849.csv`

正向 iq 从 0.75A 缓慢爬升，速度滑动窗连续超阈值（>3 rpm）检测到持续运动：

| 方向 | $i_q$ 启动力矩 | 判定转速 |
| :--- | :---: | :---: |
| 正向 | **1.05 A** | 持续 > 3 rpm |
| 力矩域 | **2.95 Nm** (Kt=2.81) | — |

### Fs vs Fc

$$F_s / F_c = 1.05 / 1.006 \approx 1.04$$

Fs 与 Fc 几乎相等——这是纯 Coulomb 摩擦的特征。说明 X12 没有明显的 Stribeck 效应（无零速驼峰）。

## 三、最终摩擦补偿公式

### L0 模型（速度 ≥ 0.13 rad/s）

电流域（推荐直接使用）：

$$\boxed{i_{q,f}(\dot{q}) = 1.006 \cdot \text{sgn}(\dot{q}) \quad [\text{A}]}$$

力矩域：

$$\boxed{\tau_f(\dot{q}) = 2.83 \cdot \text{sgn}(\dot{q}) \quad [\text{Nm}]}$$

C 代码（$v_0$ ≈ 0.03–0.05 rad/s）：

```c
iq_ff  = 1.006f * tanhf(q_dot / v0);          // A
tau_ff = 2.827f * tanhf(q_dot / v0);          // Nm
```

### 静摩擦（仅参考）

$$F_s \approx 1.05 \text{ A} \quad (2.95 \text{ Nm})$$

$F_s/F_c \approx 1.04$，与动摩擦差异极小，起动时可直接用 L0 参数。
