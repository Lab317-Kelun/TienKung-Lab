# X6 关节摩擦辨识分析报告

**关节类型**：X6-60 电机 + 行星减速器
**辨识模型**：L0 库仑 + 粘滞（Coulomb + Viscous）
**分析方法**：GUI 0xA2 速度闭环模式，自动扫频
**分析日期**：2026-07-03（更新：2026-07-04，Kt=1.5）
**数据来源**：`friction_sweep_20260703_200407/`（29 个 CSV）
**处理脚本**：`friction_gui_analysis.py`

---

## 一、实验方法

采用 **0xA2 速度闭环控制**，GUI 自动扫频 29 个转速点（25–1900 rpm 电机端）。每个点先正向恒速、再反向恒速，等实际转速到达目标（偏差 < 10% 或 8 rpm）后开始计时记录，每方向约 8 秒。同向直接切换，全程保持在速度闭环内。

## 三、稳态数据提取方法

1. **自适应速度带**：$band = \min(\max(10\% \cdot |n|, 8\text{ rpm}), 50\% \cdot |n|)$
2. **最长连续段**：从带内样本中选取最长连续组（自动跳过加减速/反转过渡）
3. **固定裁剪**：段首段尾各剪 5 个采样点（10ms @ 500Hz），消除过渡
4. **质量过滤**：iq 标准差 < max(30% × |均值|, 0.08A)
5. **半差法**：$i_{q,fric} = (i_q^+ - i_q^-) / 2$

### 缺失数据点

| 缺失点                | 原因                                          |
| :-------------------- | :-------------------------------------------- |
| 25 rpm（正向）        | 正向稳态段 < 15 样本，被质量过滤排除          |
| 75–175 rpm（单方向） | 正向/反向稳态段不足，稳定时间不够或速度波动大 |

建议后续补测这类低速点时增加稳定等待时间或放宽转矩限制。

## 六、静摩擦 $F_s$ 辨识（0xA1 力矩模式）

采用 0xA1 力矩闭环模式，iq 从 0.10A 起步，200ms 间隔步进 0.02A，速度滑动窗中位数连续 5 次超 3 rpm 判定为运动。

| 方向 | $i_q$ 启动力矩 | $F_s$ (Nm, Kt=1.5) |  判定转速  |
| :--- | :--------------: | :------------------: | :--------: |
| 正向 | **0.50 A** |         0.75         | 持续超阈值 |
| 负向 | **0.46 A** |         0.69         | 持续超阈值 |
| 均值 | **0.48 A** |    **0.72**    |     —     |

> $F_s / F_c \approx 1.27$，符合静摩擦 > 库仑动摩擦的典型关系。

## 七、最终摩擦补偿公式

### L0 库仑+粘性模型（$|\omega| \geq 0.26$ rad/s）

电流表达式（Kt 无关，推荐在电机固件/上位机中使用）：

$$
\boxed{i_{q,f}(\dot{q}) = 0.3777 \cdot \text{sgn}(\dot{q}) + 0.04581 \cdot \dot{q} \quad [\text{A}]}
$$

力矩表达式（$K_t = 1.5$ Nm/A）：

$$
\boxed{\tau_f(\dot{q}) = 0.5666 \cdot \text{sgn}(\dot{q}) + 0.0687 \cdot \dot{q} \quad [\text{Nm}]}
$$

C 代码（电流域，$v_0$ = 平滑宽度，建议 0.03–0.05 rad/s）：

```c
// L0 摩擦前馈（电流域，Kt 无关）
iq_ff = 0.3777f * tanhf(q_dot / v0) + 0.04581f * q_dot;   // A

// 或力矩域（Kt=1.5）
// tau_ff = 0.5666f * tanhf(q_dot / v0) + 0.06872f * q_dot;  // Nm

// 起动静摩擦（仅用于起动裕度，不作为前馈）
// Fs ≈ 0.48 A = 0.72 Nm (均值)，Fs/Fc ≈ 1.27
```
